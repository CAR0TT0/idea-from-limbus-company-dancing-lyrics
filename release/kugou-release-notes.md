# 都市回响 v0.8.0-beta.1-kugou.6 · 酷狗后台联动修复

基于 CAR0TT0 的 PR #4，修复酷狗最小化后歌词断连：系统歌手名 `Mili` 与原生歌词 `Mili（ミリー）` 被误判为不同歌手，后台通道无法使用。现在接受可靠跨文字体系别名，同时保留合唱、现场、翻唱、版本、时长及歌词哈希校验。

下载 `dancing-lyrics-0.8.0-beta.1-kugou.6-windows-x64.zip`，完整解压，打开酷狗播放歌曲并开启桌面歌词，再双击“启动酷狗联动.bat”。无需 Python、Git、BetterNCM 或管理员权限；可选“安装酷狗联动.bat”创建个人快捷方式。状态显示原生歌词通道或系统媒体接口时可最小化，界面兼容回退仍需要展开主窗口。

保留渐变、双语、乱码退场、字体导入、主题、预设、屏幕选择及纯音乐隐藏。设置和字体继续使用 `%LOCALAPPDATA%\DancingLyrics-Kugou\.state`。升级前退出旧歌词程序，保留该目录；从新目录重装快捷方式，自动联动应在旧版关闭后从新版重新开启。

本机验证范围为 Windows x64、酷狗 20.1.51.27967。真实最小化、托盘隐藏、冷启动和显示恢复记录见仓库验证记录；没有用模拟歌曲代替实曲。不同内部结构、32 位客户端及第二台干净电脑尚未验证，不承诺所有未来版本均兼容。Mac 的现有实验源码与网易云／QQ 下载包不在本次更新范围。
