# 都市回响 v0.8.0-beta.1

新增自定义渐变描边、渐变字芯、上下两种双语排列、独立乱码退场、显示屏幕选择及纯音乐隐藏开关；滚轮浏览设置页面时不再误改选项和数值。

效果预览文案：啊，对了！但丁。有一天，去一趟图书馆吧。

分别下载网易云音乐版和 QQ 音乐版，完整解压保留 `_internal`。更新前退出歌词程序，覆盖完整程序目录并保留 `.state`；移动网易云联动目录时需退出客户端并重新安装联动以更新路径，QQ 自动启动移动目录后需重新开启。设置、字体、预设保留。

网易云实测范围仍为 3.1.40.205461／3.1.41.205529 x64、BetterNCM 1.3.4；QQ 22.52／22.75。QQ 首次无缓存取词仍可能较慢；本轮没有扩展客户端版本范围。

- 网易云版：`dancing-lyrics-0.8.0-beta.1-netease-windows-x64.zip`。
- QQ 音乐版：`dancing-lyrics-0.8.0-beta.1-qqmusic-windows-x64.zip`。一个包自动读取 QQ 22.52／22.75，无需选择客户端版本。先开启 QQ 音乐的系统媒体控制并播放歌曲；只有 `Opened`、零时长或无进度时等待真实会话，不能把“已打开”当作已连接。
- QQ 首次双击 `启动QQ音乐联动.bat`，在“当前音乐 → QQ 音乐自动联动”开启“随 QQ 音乐启动”，默认关闭。它使用当前用户 Windows 登录监听，已有歌词实例会复用；在 QQ 音乐中手动退出歌词后不会立即重拉，重开 QQ 音乐才自动启动。关闭开关可取消监听，移动目录后需重新开启。

新选项默认保留旧体验：乱码退场、纯音乐隐藏均关闭；旧翻译优先设置迁移后保持原显示。渐变与乱码可存效果预设，语言、屏幕及纯音乐开关独立。

Windows 静音集成及真实 Qt 窗口检查通过，100%／125%／150% 缩放下可滚动访问新增控件。双语、渐变和乱码的暖缓存 P95 目标 33ms。实际数据见验证记录；本机只有单屏，多屏拔插为模拟测试，未在第二台干净电脑验证。不把演示时间数据作为真实歌曲逐字同步证据。

网易云安装器保留阶段计时、安全取消、本地官方 DLL 校验、实验性安装和恢复入口。已有不同 msimg32.dll 时不覆盖；请先确认目录与文件 SHA-256。

安装期间可选“取消操作”。下载总预算 45 秒、单次网络等待 5 秒，进程检查上限 15 秒；网络或系统调用返回后检查取消，写入阶段先安全完成或回滚。本地 DLL 必须选择实际文件路径，不能只选目录。
