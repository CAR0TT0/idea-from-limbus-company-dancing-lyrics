# 都市回响 v0.7.0-beta.2

修复 QQ 音乐部分歌曲歌词获取失败：组合搜索被 QQ 官方接口拒绝时，依次回退仅歌名及歌手在前的搜索（最多三种不同查询），仍严格核对原歌曲身份。QQ 播放音乐，都市回响只读展示桌面歌词。

Windows 下载分为两份独立 ZIP，按播放器选择：

- **QQ 音乐版**：`dancing-lyrics-0.7.0-beta.2-qqmusic-windows-x64.zip`，解压目录 `DancingLyrics-QQMusic`。打开 QQ 音乐播放歌曲，双击 **启动QQ音乐联动.bat**；无需 Python 或 BetterNCM。已实测 QQ 音乐 **22.52**。
- **网易云音乐版**：`dancing-lyrics-0.7.0-beta.2-netease-windows-x64.zip`，解压目录 `DancingLyrics-NetEase`。首次退出网易云并运行 **安装网易云联动.bat**，之后从网易云播放栏打开。无需 Python。

每份包只保留对应入口、说明和支持资源，附包版本与播放器信息；不混入 Mac 启动脚本。

QQ 联动需单独启动，不会随 QQ 音乐自动打开，也不会在 QQ 播放栏嵌入按钮。更新请退出歌词程序后覆盖完整文件，保留 `.state`。

从旧通用包升级时，先将旧 `.state` 整个复制到对应新目录；网易云版需完全退出网易云后重新安装联动更新程序路径。设置、导入字体与预设继续保留。

- 从系统媒体会话读取歌曲、进度和暂停，使用 QQ 官方整句 LRC 与可用中文译文，严格匹配，失败可重新获取。
- 沿用字体、白芯发光、卡门的声音、四种动画、参数、效果预设及三种主题。
- 效果演示文案继续使用“啊，对了！但丁。有一天，去一趟图书馆吧。”。
- QQ 暂无逐字演唱时间，不生成模拟强调数据。纯音乐及无歌词保持空白。
- 网易云仍支持 **3.1.40.205461／3.1.41.205529 x64**，原安装、卸载及插件入口保留。QQ 无需安装插件，同一时间运行一个歌词实例。
- 更新保留 `.state` 中的字体、设置和预设。请完整解压 ZIP，不能单独复制 EXE。

需要 Windows 10 1809+；音频强弱捕获需要 Windows build 20348+，较旧系统可使用轻波浪。QQ 官方歌词接口需要网络，受限或匹配不可靠时提示失败。第二台干净电脑、更多客户端版本尚未验收。Mac 已有实验包不包含 QQ 适配。

实际自动测试、原生启动及播放结果见仓库验证记录；附 SHA-256 文件。反馈请提供播放器版本、歌曲、操作步骤与截图，不要上传个人连接令牌。
