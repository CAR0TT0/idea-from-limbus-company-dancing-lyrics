# 都市回响 v0.7.0-beta.6

本版新增客户端兼容检测、在线兼容列表、网易云实验性安装与恢复入口。安装窗口区分已验证／未验证／已知不兼容，后台刷新列表，离线正常回退；未验证版本需勾选“实验性安装（未验证版本）”并单次确认。此入口保留 x64、官方框架哈希、文件冲突及退出检查，不能保证未来版本兼容。已知不兼容版本禁止安装。

网易云连接后按实际歌词字段自动选择客户端状态或本机缓存，进度接口变化时停止歌词并提示。安装备份保存在 `.state/netease-backups`；遇到问题完全退出网易云后运行 **恢复网易云联动.bat**，恢复上次安装前的插件与连接配置，仅移除该次新建且未变化的框架，保留设置、字体及预设。QQ 新增媒体会话、有效进度与歌词来源检测提示，继续使用现有系统媒体接入。

仍只声明已有网易云两个完整构建和 QQ 22.52／22.75 的实测范围。测试中的新版本号为夹具，未冒充新客户端验证；在线列表只能调整许可，接口变化仍需更新代码。详见仓库“客户端兼容维护”说明。

QQ 音乐版新增可选的 **随 QQ 音乐启动**。首次打开歌词程序后勾选开关，之后启动 QQ 音乐就会自动显示桌面歌词，设置面板默认收在系统托盘；再次双击入口会恢复已有窗口。默认关闭，不修改 QQ 音乐文件，也不控制播放。

## 按播放器下载

- **QQ 音乐版**：`dancing-lyrics-0.7.0-beta.6-qqmusic-windows-x64.zip`，解压目录 `DancingLyrics-QQMusic`。已实测 QQ 音乐 **22.52／22.75**，同一个包，无需选择客户端版本；无需 Python、BetterNCM 或客户端插件。
- **网易云音乐版**：`dancing-lyrics-0.7.0-beta.6-netease-windows-x64.zip`，解压目录 `DancingLyrics-NetEase`。首次退出网易云并运行 **安装网易云联动.bat**，之后从网易云播放栏打开；仍支持 **3.1.40.205461／3.1.41.205529 x64**。

请完整解压，保留 EXE 旁的整个 `_internal` 文件夹。两份包使用相同歌词引擎，各自独立的入口、说明及支持资源；同一时间选择一个播放源。附 SHA-256 校验文件。

## QQ 自动启动三步

1. 将 QQ 音乐版 ZIP 完整解压到准备长期保留且可写的目录。
2. 打开 QQ 音乐播放歌曲，首次双击 **启动QQ音乐联动.bat**，确认已连接且歌词已同步。
3. 在 **当前音乐 → QQ 音乐自动联动** 勾选 **随 QQ 音乐启动**。

开启后立即监听，之后在 Windows 登录时运行后台监听；QQ 启动后自动显示歌词。右键系统托盘图标可打开设置，无需管理员权限。关闭开关取消本目录的登录启动，监听约 2 秒内退出，当前歌词继续运行。手动退出歌词后本次 QQ 会话不会反复拉起，重开 QQ 音乐后恢复。QQ 播放栏不增加按钮。

Windows 可能延迟登录启动，任务管理器或系统策略也可能禁用它；遇到这种情况先手动打开 BAT，再检查“启动应用”。本机已验证原生开关、监听、自动启动到托盘、重复启动恢复及真实歌词；尚未通过注销／重启 Windows、第二台电脑或长期运行验收。

更新 QQ 到 **22.75** 后如提示等待，请确认 QQ 的“系统媒体控制”已开启并播放歌曲。客户端刚打开可能只有 `Opened` 状态、零时长和零进度，歌词应用会安全等待，直到取得真实时间轴。现有系统媒体及 QRC 接入可继续使用，无需修改 QQ 文件。

22.75 真实歌曲验证读取到 76 句歌词、309 个字词区间，播放推进、暂停稳定后冻结、效果切换及播放状态恢复通过。暂停后观察到一次客户端延迟时间轴校正，应用继续跟随真实位置；本轮未重新验收 22.75 手工拖动和切歌。

## 更新与原有功能

- **QQ 更新或删除前**：先关闭“随 QQ 音乐启动”，等待约 2 秒，再从托盘退出歌词程序。更新保留 `.state`；移动目录或换新目录后，从新目录手动启动并重新开启开关。
- **网易云更新**：完全退出网易云和歌词程序，覆盖完整文件并再次安装联动更新路径，保留 `.state`。从旧通用包迁移时，将旧 `.state` 整个复制到对应新目录。
- 设置、导入字体与效果预设保留。沿用白芯发光、卡门的声音、四种动画、参数及三种主题，修复显式“退出”可能被关闭到托盘逻辑拦住的问题。
- 效果演示文案继续使用“啊，对了！但丁。有一天，去一趟图书馆吧。”。
- QQ 仍优先读取严格匹配的本地 QRC 缓存，支持真实字词时间与中文译文；未命中时沿用官方接口兜底，切歌后短时检查迟到缓存。**首次播放及无缓存歌曲仍可能较慢，不能保证所有歌曲和网易云一样快。**
- 无真实字词时间时保留整句动画；纯音乐及无歌词保持空白。音乐、暂停、切歌、进度和音量仍在音乐播放器中操作。

需要 Windows 10 1809+，本机验证系统为 Windows 11 x64。音频强弱捕获要求 Windows build 20348+，较旧系统可选择轻波浪。更多 QQ 版本、QQ 首次写盘延迟及第二台干净电脑尚未验收；本轮网易云验证安装与启动，未重复实曲播放。现有 Mac 实验包保持原样。
