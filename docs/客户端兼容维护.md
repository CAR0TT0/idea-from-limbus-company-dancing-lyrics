# 客户端兼容检测与恢复

## 用户操作

网易云更新后，完全退出客户端，打开“安装网易云联动.bat”。窗口自动读取当前 EXE 完整版本，后台尝试刷新兼容列表；也可点击“联网刷新兼容列表”。已验证版本正常安装；未验证版本默认不安装，可勾选“实验性安装（未验证版本）”并单次确认；已知不兼容版本始终阻止安装。

实验性安装只跳过版本白名单，仍检查 x64、官方 BetterNCM 1.3.4 SHA-256、客户端已退出和未知文件冲突。不能保证未来版本兼容。音乐由原客户端控制，安装器不会结束音乐进程。

安装后无法打开网易云时，完全退出网易云，再运行“恢复网易云联动.bat”，选择“恢复上次安装”。也可在安装窗口点击同名按钮。它恢复本目录最近一次成功安装前的插件、连接配置及安装记录，个人设置、字体及预设保留。只移除该次新建且哈希未变化的框架；原有框架保留。文件被后续修改或存在其他共用插件时拒绝自动恢复，请保留备份并反馈。卸载仍只删除本插件、保留共用框架。

备份位于 `.state/netease-backups/<备份编号>`。备份含连接令牌，不要公开上传。移动或升级程序时保留整个 `.state`。没有备份的旧版安装无法用此入口恢复；若已有框架本身不兼容，恢复插件也无法修复框架，需要更新框架或使用已验证客户端。

QQ 音乐没有注入安装或版本白名单；当前音乐页显示“尚未发现媒体会话”“等待歌曲与有效进度”或歌曲与进度可用，并提示歌词来源。先确认 QQ 的系统媒体控制开启并播放歌曲。缓存未命中或未知格式使用现有联网兜底；无法取得真实时间轴时等待并提示，不伪造播放位置。

## 在线列表

唯一来源为本仓库 main 分支的 [compatibility/clients.json](../compatibility/clients.json)，通过 HTTPS 获取，不下载或执行代码，不接受远程 DLL、下载地址或 JavaScript。格式版本 `schema_version: 1`；每次修改递增 `revision`。下载上限 64KiB、超时 5 秒、最多 128 条，拒绝来源跳转、非法字段和版本回退。

条目使用完整四段构建号和 `verified`／`blocked` 状态；未列出的版本是未验证。在线条目可撤销内置已验证版本。有效在线缓存保留 7 天，过期后已验证的新增版本回到未验证，已知不兼容记录继续保留，直到有效的新列表明确解除。损坏或网络失败不覆盖原缓存，使用内置列表或有效缓存。

示例仅用于测试，不表示网易云 3.1.42.123456 已验证：

```json
{"schema_version":1,"revision":2,"netease":[
  {"version":"3.1.42.123456","status":"blocked","reason":"测试示例：播放接口发生变化"}
]}
```

发布新的已验证条目前，必须在对应真实构建验证框架加载、歌曲身份、歌词、进度推进、暂停、跳转和切歌。列表可以改变安装许可，不能修复已变更的接口或框架；这类变化需要更新代码和安装包。当前列表只列出原有两个实测网易云构建，未将测试夹具冒充真实新版本。

## 接入与限制

安装器将目标版本与状态写入本机连接配置，并生成适合目标版本家族的插件 manifest 范围。接收端仅额外接受本机安装授权的版本家族，网络包不能自行授权新版本。BetterNCM 返回三段版本，运行时授权粒度为三段版本家族，无法独立核对完整构建号；完整构建检查在安装时完成。升级到其他版本家族后需要重新运行安装器。

插件优先使用带歌曲标识的歌词状态，缺少标识时尝试客户端按歌曲 ID 提供的本机缓存；已有其他歌曲标识的旧歌词绝不改绑。进度接口只通过宿主原有订阅流读取，无法订阅时停止本次歌词联动并提示、自动重试，不替换网易云原生播放回调。框架未加载、按钮结构改变或接口完全替换时仍可能需要人工适配。

## 开发验证

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
.\启动.bat -Smoke -ReportDirectory "$PWD\artifacts\compatibility-source"
```

隔离目录自动验收可对成品 EXE 使用 `--install-netease`／`--restore-netease`、`--client-directory`、`--profile-directory` 和 `--installer-report`。显式 `--experimental-netease` 表示本次允许未验证版本；图形界面仍要求单次确认。请仅对隔离客户端使用自动验收，普通用户使用图形界面和 BAT 即可。
